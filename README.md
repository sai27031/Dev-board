# DevBoard 🚀

A developer task and project tracker built with React.

## Features
- 🔐 Login & Signup pages
- 📋 Kanban board with To Do, In Progress, Done columns
- ➕ Add tasks with priority levels (High, Medium, Low)
- 🗑️ Delete tasks
- 🔄 Move tasks between columns
- 🌙 Dark mode toggle

## Tech Stack
- React.js
- Tailwind CSS
- React Router DOM
